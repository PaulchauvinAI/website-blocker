# Website Blocker

A Chrome extension to block distracting websites during your working hours to help you stay focused and productive.

## Features

- **Time-based Website Blocking**: Block specific websites during configured time periods
- **Customizable Redirect**: Choose where to redirect when attempting to access blocked sites
- **Simple Management**: Easy-to-use interface for adding and removing blocked websites
- **Precise Time Control**: Set blocking schedules with hour and minute precision

## Installation

1. Download or clone this repository
2. Open Chrome and navigate to chrome://extensions/
3. Enable "Developer mode" in the top-right corner
4. Click "Load unpacked" and select the folder containing this extension
5. The Website Blocker extension is now installed and ready to use

## Usage

1. Click on the extension icon in your Chrome toolbar to open the settings
2. Set your blocking schedule (start and end times)
3. Enter a redirect URL (where you'll be sent when trying to access blocked sites)
4. Add the domains you want to block (e.g., facebook.com, youtube.com)
5. Click "Save Settings" to apply your changes
